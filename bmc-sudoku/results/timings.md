## Test set

Solvable puzzles chosen to be hard for constraint solvers rather than for humans:

- `wiki.txt`: standard example, Wikipedia Sudoku article
- `ai_escargot.txt`: Arto Inkala, 2006
- `inkala_2012.txt`: Arto Inkala, 2012, via sudokuwiki.org
- `norvig_a/b/c.txt`: from norvig.com/hardest.txt
- `clue17.txt`: 17-clue puzzle, the proven minimum for a unique solution
- `empty.txt`: no givens, worst case for the givens constraints

Unsolvable puzzles, each built by adding one conflicting given to a solvable
puzzle so the contradiction is not visible in a single row, column or box:

- `row.txt`: duplicate digit in a row (shallow contradiction)
- `hidden.txt`: contradiction only reachable after propagation
- `escargot_plus.txt`, `inkala_plus.txt`: as above, on the two hardest puzzles

Multi-solution puzzles (`puzzles/multi/`) were generated by stripping clues from
a solved grid and counting solutions with an independent backtracking solver, so
the expected counts do not depend on CBMC.
